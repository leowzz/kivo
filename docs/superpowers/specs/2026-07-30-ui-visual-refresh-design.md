# Kivo Helper UI 视觉与布局优化设计

日期：2026-07-30
状态：已获用户批准

## 目标

对 Kivo helper（Tauri 2 桌面应用）进行 UI 优化，两个核心动机：

1. **视觉风格升级**：从朴素灰绿工程风升级为精致现代浅色系（参考 Linear / Raycast 浅色模式），保留绿色品牌识别。
2. **布局与信息效率**：全部视图统一优化布局节奏，首页仪表盘为重点。

## 约束

- 技术方案：**设计 Token + 手写 CSS 重构**（方案 A）。零新依赖，符合项目既定的"无 UI 组件依赖"原则（见 `2026-07-27-helper-tauri2-design.md`）。
- 暂不做暗色模式，但所有颜色值收敛为 `:root` 上的 CSS 变量，未来加暗色只需覆盖变量。
- 不改组件 props、状态逻辑与 Tauri 命令面；纯表现层重构。
- 现有测试全部保持通过；仅允许同步更新测试中的 className 选择器断言（不改语义）。

## 设计 Token 体系

新建 `src/styles/tokens.css`，全部样式值收敛为五组 CSS 变量：

### 色彩

- `--gray-1` ~ `--gray-12`：Radix 式 12 档冷调灰阶（约 `#fbfcfb` → `#1a211e`）。1-3 表面层、4-6 边框/分隔、7-10 次要文字、11-12 主文字。
- `--green-1` ~ `--green-12`：品牌绿完整色阶，`--green-9` ≈ 现有 `#177457`。用于主按钮、选中态、连接态、热力图。
- `--amber-*` / `--red-*`：各 3 档（背景、边框、文字），用于警告、错误、危险操作。

### 表面分层

- `--bg-app`（最底层微灰）→ `--bg-surface`（卡片/面板纯白）→ `--bg-raised`（弹窗/悬浮）
- `--border-subtle`（极浅 rgba 分隔）/ `--border-default` / `--border-strong`
- 阴影三档（均为双层柔和阴影，低透明度）：
  - `--shadow-1` 卡片静止
  - `--shadow-2` hover/悬浮
  - `--shadow-3` 模态

### 字阶

- `--text-11/12/13/14/17/20/24`，字重 450/550/650/750
- 数字（指标卡、日志时间、GPIO 输入）使用 `tabular-nums`

### 圆角与间距

- `--radius-6/8/10/12`：按钮/输入 8，卡片 10，模态 12
- 4px 基网格 `--space-4/8/12/16/20/24/32`

### 文件拆分

替代单个 `src/App.css`：

- `src/styles/tokens.css`：变量
- `src/styles/base.css`：reset、焦点环、滚动条
- `src/styles/app.css`：壳/顶栏/侧栏
- `src/styles/views.css`：各视图

## 整体布局与导航

- **顶栏**：52px → 48px。品牌区去掉右侧分隔线；连接状态改为胶囊徽章（全圆角 + 状态点 + 等宽端口名，连接时状态点呼吸动画）；保存状态收窄为纯文字态，错误时才显示重试按钮。
- **侧栏**：184px → 200px，背景为 `--bg-app` + 右侧 1px 半透明边框。导航项圆角 8px、图标 16px；激活态 = `--green-3` 底 + `--green-11` 字 + 左侧 3px 指示条；分组标签小字号。"配置文件"入口固定于侧栏底部。
- **工作区**：所有视图统一 24px 页边距 + 16px 卡片间距；页面头部统一为 64px 区域（标题 17px/650 + 副标题 12px 灰 + 右侧操作区）。
- **三栏视图**（行为/硬件/布局）：动作面板从固定 360px 改为 `minmax(320px, 380px)` 弹性；内容区加 `max-width` 内约束，宽屏不再空旷拉伸。
- **错误提示**：整行横幅改为顶栏下方右上角浮动 toast（圆角 + 阴影），不再挤压工作区高度。
- **响应式**：断点保持 980px / 680px，行为不变，数值对齐新 token。
- **焦点环**：统一为 2px `--green-8` 外发光 + 圆角跟随控件。

## 首页仪表盘（重点）

- 页面头：标题"按键概览" + 型号名副标题；右侧连接胶囊（与顶栏语言一致）。
- **指标卡**：图标放入 `--green-3` 圆角方块（28×28）；数值 28px/700 `tabular-nums`；标签 12px 灰；hover 时 `--shadow-1` → `--shadow-2` 微浮起。
- **热力图**：连续透明度改为 5 档阶梯色（`--green-2/4/6/8/10`）；无数据单元格为 `--gray-3` 虚线边框；单元格内标签 + 数值 + 最近日期三层排布；`title` 提示保留。
- **活动日志**：右栏 360px → `minmax(300px, 340px)`；条目卡片化（8px 间距替代分割线），时间 11px 等宽灰；空状态居中图标 + 文案。
- 主区内容 `max-width 880px` 居中。

## 按键行为页

- 页面头右侧显示当前选中键的面包屑胶囊（如 `已选中: UP`）。
- 按键圆角 6 → 8px；底阴影改柔和分层；hover 微浮；选中态 = 2px `--green-8` 环 + `--green-2` 底；按下态保持绿色填充 + 120ms 回弹动画；动作数角标改为 `--green-9` 实心小圆点 + 数字。
- 动作面板：头部显示按键标签；动作卡片头部加类型图标（粘贴/快捷键）；底部"添加动作"按钮改为虚线边框 drop-zone 风格，hover 变绿。
- 无选中键时动作面板显示引导文案。

## 硬件映射页

- 信号源卡片头部加类型图标 + 更清晰标题层级。
- 映射表格行高 38 → 44px；选中行 = `--green-2` 底 + 左侧 3px 绿条（与侧栏激活态统一）；GPIO 输入框等宽数字。
- 学习面板从底部折叠 `<details>` 提升为醒目引导卡片：未学习时虚线边框 + 图标 + "开始学习"主按钮；学习中为 amber 状态卡 + 脉冲动画；安全确认勾选框加大。
- 防抖输入改为一行内联字段组。

## 布局编辑器与数据页

- 布局编辑器模态：圆角 12px、`--shadow-3`、头部加副标题；分组卡片间距 12px；底部操作栏加分隔。
- 数据页：单列 520px 改为卡片式分组——"型号选择"卡 + "导入/导出"卡（2×2 按钮网格）+ "危险操作"卡（删除隔离、红边框浅红底）。
- 确认弹窗：圆角 12、`--shadow-3`、标题区加危险/警告图标；摘要条保留琥珀色左边条。

## 错误处理

表现层重构不改变现有错误处理逻辑（runtime error、保存失败重试、配置错误等）。错误展示从横幅迁移为浮动 toast 后，保留关闭按钮与 `role="alert"` 语义。
