# Kivo Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Kivo's packaged application icons with an electric-blue programmable-keycap mark.

**Architecture:** `gpt-image-2` produces one opaque 1024 x 1024 PNG. macOS `sips` and the Tauri icon generator derive platform assets while the configuration retains the existing filenames.

**Tech Stack:** OpenAI Image API (`gpt-image-2`), bundled `image_gen.py`, Tauri CLI, macOS `sips`.

## Global Constraints

- Use `gpt-image-2` at `1024x1024` and high quality.
- Use a graphite rounded-square background, electric-blue raised keycap, and white short horizontal function mark.
- Include no text, telephone imagery, watermark, or transparent background.
- Preserve all existing icon filenames and dimensions under `src-tauri/icons/`.
- Render the macOS template tray icon as a transparent monochrome keycap outline.
- Do not change Tauri configuration or application code.

### Task 1: Generate And Package The Icon

**Files:**
- Create: `output/imagegen/kivo-icon-source.png`
- Modify: `src-tauri/icons/icon.png`, `32x32.png`, `64x64.png`, `128x128.png`, `128x128@2x.png`
- Modify: `src-tauri/icons/icon.icns`, `icon.ico`, `tray-icon.png`, `tray-icon.svg`
- Modify: `src-tauri/icons/Square30x30Logo.png`, `Square44x44Logo.png`, `Square71x71Logo.png`, `Square89x89Logo.png`, `Square107x107Logo.png`, `Square142x142Logo.png`, `Square150x150Logo.png`, `Square284x284Logo.png`, `Square310x310Logo.png`, `StoreLogo.png`

**Interfaces:**
- Consumes: `src-tauri/tauri.conf.json` icon references.
- Produces: valid files at every existing Tauri icon path.

- [x] **Step 1: Generate the source PNG**

Run:

```bash
python "$CODEX_HOME/skills/.system/imagegen/scripts/image_gen.py" generate \
  --model gpt-image-2 --size 1024x1024 --quality high \
  --prompt "Use case: logo-brand. Asset type: desktop app icon. A graphite rounded-square app icon with one centered raised electric-blue programmable keyboard keycap. Place one short white horizontal function mark on the keycap. Clean industrial hardware tool aesthetic, thick simple geometry, high contrast, crisp at 16 pixels. No text, letters, telephone imagery, circuitry, watermark, transparency, gradients, shadows outside the keycap, or extra objects." \
  --out output/imagegen/kivo-icon-source.png
```

Expected: a 1024 x 1024 opaque PNG with the approved single-keycap design.

- [x] **Step 2: Inspect the source and reject unsuitable output**

Run: `sips -g pixelWidth -g pixelHeight output/imagegen/kivo-icon-source.png`.

Expected: `pixelWidth: 1024` and `pixelHeight: 1024`; visually verify the absence of text and phone imagery.

- [x] **Step 3: Derive all existing package icons**

Run the installed Tauri icon generator against `output/imagegen/kivo-icon-source.png`, preserving existing application-icon filenames and dimensions. Replace `tray-icon.svg` with the transparent monochrome keycap outline and export it as `tray-icon.png` at 36 x 36, since macOS renders it as a template icon.

- [x] **Step 4: Verify exported formats and dimensions**

Run `find src-tauri/icons -maxdepth 1 -type f -exec file {} \;` and `find src-tauri/icons -maxdepth 1 -type f -name '*.png' -exec sips -g pixelWidth -g pixelHeight {} \;`.

Expected: every configured PNG retains its original dimensions; `icon.icns` and `icon.ico` remain valid icon containers.

- [x] **Step 5: Verify the desktop build configuration**

Run:

```bash
cargo check --manifest-path src-tauri/Cargo.toml
git diff --check
git status --short
```

Expected: Cargo exits 0; no whitespace errors; only icon assets and the source image are changed.

- [ ] **Step 6: Commit**

```bash
git add output/imagegen/kivo-icon-source.png src-tauri/icons
git commit -m "feat: refresh Kivo app icon"
```
