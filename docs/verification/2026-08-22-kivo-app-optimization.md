| 渐进触发 | 默认只显示“按下”；释放、长按和双击折叠；阈值以秒显示 | 通过 |
| 三步首次设置 | 识别与命名、选择模板、实体按键验证；包含成功、失败和 15 秒超时状态 | 自动化通过，实体未测 |

| 测试与活动 | 测试页展示实时输入和动作结果；成功/失败按设备、按键和动作类型持久化；活动提供失败聚合、未使用按键和七日数据 | 自动化通过，实体未测 |

| 可逆编辑 | 普通配置和 Product Device 各自维护撤销/重做历史；导入/恢复显示数量差异；快照记录创建时间和来源设备 | 通过 |

| 响应式和可访问性 | 390px 单列顺序滚动，无画布/动作面板重叠；按键支持方向键、Enter、Space 和可访问名称 | 通过 |

## 2. 自动化结果

| 检查 | 结果 |
| --- | --- |
| `npm test -- --run` | 23 个测试文件、297 个测试全部通过 |
| `npm run build` | 生产构建通过 |
| `npx tsc --noEmit --pretty false` | 通过 |
| `cargo test --manifest-path src-tauri/Cargo.toml` | 单元测试 451 个通过、1 个忽略；集成测试 3 个通过 |
| `cargo fmt --manifest-path src-tauri/Cargo.toml --check` | 通过 |
| `git diff --check` | 通过 |

重点回归覆盖了正式入口挂载、精确设备选择、离线设备、动作结果持久化、首次设置验证、三个模板入口、学习设备锁定、共享配置、普通配置与 Product Device 撤销/重做、快照元数据、导入恢复摘要和键盘导航。

领域不变量保持不变：候选设备仍需身份校验，设备操作按精确 Device ID 定位，Runtime Assignment 继续按设备独立保存，共享配置只在用户明确复制后生成设备专用副本。
